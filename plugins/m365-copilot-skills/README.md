# m365-copilot-skills

Authoring tooling for Microsoft 365 Copilot custom skills.

## What it includes

- `skills/create-a-skill/SKILL.md` - interviews the operator and writes an installable `SKILL.md` for Word, Excel, PowerPoint, Copilot Cowork, or AI in SharePoint.
- `skills/create-a-skill/references/` - portable skill spec, host paths, install notes, examples, and review checks.
- `skills/create-a-skill/assets/` - deployable prompts for Agent Builder and SharePoint-native delivery.

## Notes

Host paths and limits in `office-host-guide.md` were verified on 2026-08-17 and are separated from the host-neutral spec so path changes stay isolated.
