# Review checklist

Run these checks before delivery:

- [ ] Purpose is clear and measurable.
- [ ] Inputs are complete and unambiguous.
- [ ] Output format is explicit.
- [ ] Steps are ordered and testable.
- [ ] Boundaries and refusals are explicit.
- [ ] Missing-data behavior is defined.
- [ ] Host install notes match the chosen host.

Failure triage:

1. If scope drift appears, tighten the intent and exclusions.
2. If outputs vary, add a strict output contract.
3. If unsafe requests pass, strengthen refusal rules.
