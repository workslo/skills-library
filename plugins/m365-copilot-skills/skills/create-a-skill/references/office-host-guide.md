# Microsoft 365 host guide

Verified: 2026-08-17

This file holds host-specific details that change over time.

## Hosts and install notes

- **Word, Excel, PowerPoint**: install custom skills from each host's Copilot skill management surface.
- **Copilot Cowork**: install through the Copilot skill configuration panel.
- **AI in SharePoint**: install via site-level AI skill configuration and attach site context.

## Limits and compatibility

- Keep system instruction blocks concise and explicit.
- Avoid host-specific UI assumptions in core skill text.
- Keep one source skill and adapt only host install notes per target.
