# Worked examples

## Word example

Task: draft a compliance-ready client update.

- Input: issue summary, timeline, owner, and next action.
- Output: short client note with a clear status line and action list.

## Excel example

Task: reconcile break totals against a control total.

- Input: break table, control total, tolerance.
- Output: tie-out result with unmatched rows and a follow-up queue.

## PowerPoint example

Task: build a one-page leadership update.

- Input: KPI changes, drivers, risks.
- Output: slide-ready summary with three bullets for actions.
